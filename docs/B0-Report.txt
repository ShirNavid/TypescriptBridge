KEY ARCHITECTURAL FINDINGS:

    - HTTP transport is required. file:// does not work with the VS
      debug adapter, even though Edge DevTools handles it fine.
    - .esproj is required. Open Folder mode does not work for
      TypeScript debugging with source maps in VS 2026.
    - launch.json must be in .vscode/ and is read only inside an
      .esproj project.
    - StartupCommand in .esproj is a command to run, NOT a URL.
    - Node.js alone is sufficient for the HTTP server. No npm
      dependencies, no package.json, no third-party server.
    - The .esproj SDK version must match the installed VS SDK exactly
      (1.0.6165494 on this machine).
